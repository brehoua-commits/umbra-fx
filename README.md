# Umbra-FX 🌑

`umbra-fx` is a lightweight, high-performance CLI tool designed for digital artists and web developers who want to automate the batch processing of assets with a dark, minimalist, and expressionist aesthetic. 

It bridges the gap between raw programmatic workflows and moody, atmospheric visual rendering.

## Features
- **Atmospheric Filtering:** Quick-apply dark charcoal and minimalist shadow profiles to raw assets.
- **CLI Automation:** Seamless integration into continuous integration or local asset pipelines.
- **Zero-Bloot:** Built with minimal dependencies for fast execution.

## Installation

```bash
npm install -g umbra-fx
